# Library data

| Path | What it is | Licence |
|---|---|---|
| `library.json` | The starter catalogue (titles, authors, sections, links to public-domain sources) | Same as the code (AGPL-3.0) |
| `texts/ramcharitmanas-growse.txt` | F. S. Growse's 1914 translation of the Ramcharitmanas, cleaned from a scan | Public domain |
| `samples/*.json` | Ready-made sample lessons | See below |

**Sample lessons**
- Samples for public-domain books (Bennett, Allen, Sun Tzu, Carnegie & Esenwein, Kabir/Tagore) quote only those public-domain texts.
- `samples/100-decisions-before-the-first-brick.json` is based on *The 100 Decisions Before the First Brick*, which is **© its author, all rights reserved**. It is included only so the official app can show this sample. It is **not** covered by the AGPL and may not be reused without permission.

Book texts uploaded by learners or the admin are stored in the app's database and file storage, never in this repository.
